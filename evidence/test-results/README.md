# Test Results Evidence

Place sanitized output from each synthetic test harness here.

Suggested files:
- `single-source-test-results.png` or `.csv`
- `distributed-test-results.png` or `.csv`
- `password-spraying-test-results.png` or `.csv`
- `test-summary.md`

For each run, record:
- Date/time and workspace type (lab/non-production).
- Query/test version or Git commit.
- Expected and actual detection counts.
- PASS/FAIL results.
- Any deviations and remediation.

Do not claim that a test passed unless you executed it in the target KQL environment. The repository contains test queries, not pre-verified runtime output.
